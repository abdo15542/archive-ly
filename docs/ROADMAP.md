# خارطة التنفيذ

## المنجز في المستودع
- [x] هيكل Node.js متعدد التطبيقات وواجهة React RTL أولية.
- [x] مخطط PostgreSQL للمستخدمين والتصنيفات والوثائق وسجل التدقيق.
- [x] مصادقة JWT وإنشاء حساب المسؤول الأول.
- [x] رفع الوثائق والتحقق من ترويسة PDF/JPEG/PNG/TIFF وحساب SHA-256.
- [x] البحث في البيانات الوصفية والنص المستخرج.
- [x] طابور OCR في PostgreSQL وعامل مستقل يحجز المهام بأمان باستخدام SKIP LOCKED.
- [x] OCR عربي/إنجليزي عبر Tesseract واستخراج PDF الرقمي عبر Poppler، مع معالجة أول 15 صفحة من PDF الممسوح افتراضياً.
- [x] إعادة محاولة OCR، قراءة حالة الوثيقة وتعديل بياناتها.
- [x] Docker Compose للخادم وقاعدة البيانات وعامل OCR مع تخزين دائم للملفات.
- [x] GitHub Actions لاختبار API وبناء الواجهة.

## الخطوات التالية
- [ ] تشغيل CI والتحقق من نجاح جميع الوظائف وإصلاح أي إخفاق.
- [ ] اختبارات تكامل فعلية مع PostgreSQL وملفات PDF وصور عربية مرجعية.
- [ ] واجهة مراجعة النص المستخرج وتعديل OCR يدوياً وعرض حالة المهام.
- [ ] إدارة المستخدمين والأدوار والصلاحيات من لوحة الإدارة.
- [ ] سجل تدقيق قابل للبحث والتصفية من لوحة الإدارة.
- [ ] عارض PDF متقدم وطباعة وتنقل بين الصفحات.
- [ ] دعم أجهزة المسح الضوئي عبر تطبيق Android أو TWAIN/SANE على سطح المكتب.
- [ ] تخزين ملفات آمن خارج web root، وفحص برمجيات خبيثة، وحدود تحميل قابلة للضبط.
- [ ] نسخ احتياطي مجدول واختبار الاستعادة ومراقبة المهام.
- [ ] إعداد Capacitor/Android وGitHub Actions لإنتاج APK بعد اكتمال الواجهة والاختبارات.

العناصر في قسم الخطوات التالية ليست منفذة بعد. لا تُعتبر المنظومة إصداراً إنتاجياً قبل اجتياز الاختبارات والتدقيق الأمني والتحقق من النشر.
