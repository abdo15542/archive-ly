# خارطة التنفيذ

## المنجز في المستودع
- [x] هيكل Node.js متعدد التطبيقات وواجهة React RTL أولية.
- [x] مخطط PostgreSQL للمستخدمين والتصنيفات والوثائق وسجل التدقيق.
- [x] مصادقة JWT وإنشاء حساب المسؤول الأول.
- [x] رفع الوثائق والتحقق من ترويسة PDF/JPEG/PNG/TIFF وحساب SHA-256.
- [x] البحث في البيانات الوصفية والنص المستخرج.
- [x] طابور OCR في PostgreSQL وعامل مستقل يحجز المهام بأمان باستخدام SKIP LOCKED.
- [x] OCR عربي/إنجليزي عبر Tesseract واستخراج PDF الرقمي عبر Poppler، مع معالجة أول 15 صفحة من PDF الممسوح افتراضياً.
- [x] إعادة محاولة OCR، قراءة حالة الوثيقة وتعديل بياناتها.
- [x] واجهة أولية لمراجعة النص المستخرج وحالة OCR.
- [x] واجهات API إدارية لإدارة المستخدمين والأدوار وسجل العمليات.
- [x] Docker Compose للخادم وقاعدة البيانات وعامل OCR مع تخزين دائم للملفات.
- [x] GitHub Actions لاختبار API وبناء الواجهة.
- [x] عارض PDF داخل الواجهة وإدارة التصنيفات.
- [x] أدوات نسخ احتياطي لقاعدة البيانات والوثائق مع SHA-256 والتحقق قبل الاستعادة.
- [x] جدولة النسخ الاحتياطي عبر خدمة Docker مستقلة مع سياسة احتفاظ قابلة للضبط واختبارات آلية لحذف النسخ القديمة بأمان.

## الخطوات التالية
- [ ] اختبارات تكامل فعلية مع PostgreSQL وملفات PDF وصور عربية مرجعية، بما فيها تجربة استعادة على قاعدة منفصلة.
- [ ] محرر لتصحيح نص OCR يدوياً مع حفظ سجل النسخ والمراجعات.
- [ ] واجهة رسومية لإدارة المستخدمين والأدوار والصلاحيات.
- [ ] واجهة رسومية لسجل التدقيق مع البحث والتصفية.
- [ ] تخزين ملفات آمن خارج web root، وفحص برمجيات خبيثة، وحدود تحميل قابلة للضبط.
- [ ] مراقبة طابور OCR وتنبيهات للمهام المتعثرة وإعادة المحاولة من لوحة الإدارة.
- [ ] نسخ احتياطية خارجية مشفرة واختبار استعادة دوري موثق.
- [ ] إعداد Capacitor/Android وإنتاج APK بعد اكتمال الواجهة والاختبارات.

العناصر المنجزة تعني أن الكود أضيف إلى المستودع واختباراته المحددة أُدرجت في CI؛ ولا تعني أن خدمة النسخ المجدول شُغّلت على خادم المستخدم أو أن استعادة إنتاجية اختُبرت. لا تُعتبر المنظومة إصداراً إنتاجياً قبل اجتياز اختبارات التكامل والتدقيق الأمني والتحقق من النشر.
