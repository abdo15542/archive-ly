# أرشيف | ARCHIVE LY

نظام عربي لإدارة وأرشفة الوثائق إلكترونياً.

## البنية
- `apps/api`: واجهة REST وخدمات المصادقة والوثائق.
- `apps/web`: واجهة المستخدم (ستُضاف في المرحلة التالية).
- `infra`: إعدادات التشغيل المحلي.
- `docs`: توثيق النظام.

## المتطلبات
Node.js 20+ و PostgreSQL 15+.

## التشغيل الأولي
1. انسخ `.env.example` إلى `.env` وعدّل بيانات الاتصال.
2. نفّذ `npm install`.
3. نفّذ `npm run db:migrate`.
4. نفّذ `npm run dev`.

## الحالة
هذه بداية التنفيذ وليست إصداراً إنتاجياً نهائياً. ميزات OCR العربي والواجهة وتطبيق Android ستضاف وتُختبر على مراحل. لا تضع أسراراً أو مفاتيح حقيقية في Git.
